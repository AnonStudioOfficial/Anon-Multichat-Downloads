# ANON Multichat

Aplicativo gratuito para Windows x64 que reúne chats e eventos de transmissões ao vivo, com overlays e painéis para OBS.

Este repositório distribui o aplicativo. O desenvolvimento é mantido em repositório privado.

## Download e instalação

1. Abra **[Releases](https://github.com/AnonStudioOfficial/Anon-Multichat-Downloads/releases)** e baixe `ANON-Multichat-6.1.0-B7.2-Windows-x64.zip`.
2. Extraia o ZIP inteiro para uma pasta local.
3. Execute `Multichat.exe` dentro da pasta extraída.
4. Configure suas plataformas no botão **Plataformas**.

Esta é uma versão Beta. Leia `README-TESTERS-PT-BR.md`, incluído no ZIP, para conhecer os recursos e limitações.

## OBS

Mantenha o aplicativo aberto. Nas configurações de overlays, copie os links permanentes para as fontes de navegador ou painéis personalizados do OBS. Não compartilhe os links pareados.

## Dados e preferências

Os dados ficam em `%APPDATA%\AnonMultichat-Beta-B7.2`. Cada usuário configura suas próprias contas. O download não inclui contas ou sessões configuradas.

## Reportar problemas

Abra uma Issue com os passos para reproduzir e a versão utilizada. Não envie senhas, tokens, cookies, links pareados ou a pasta do perfil.
